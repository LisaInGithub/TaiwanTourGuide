# 🧭 台灣小導遊 Taiwan Tour Guide

像導遊一樣的台灣旅遊 App 原型:**推薦去哪玩、規劃交通路線、告訴你哪裡有好吃好玩的。**

## 功能
- 💬 **問導遊**:「從台北到花蓮怎麼去?」「台南有什麼好吃的?」
- ✨ **依興趣推薦景點**(自然、老街、夜市、溫泉、親子、雨天室內…)
- 🗓️ **自動排行程**:選天數、步調、偏好,產生每日行程(含交通與美食)
- 🚆 **交通規劃**:高鐵/台鐵/捷運/客運/飛機,提供最快、最省錢、最少轉乘方案
- 🍜 **吃喝玩樂**:各城市小吃、夜市、伴手禮
- ⭐ **收藏與串聯路線**、📍 **附近景點**、📱 **可安裝、離線可用(PWA)**

涵蓋 20 個地點:台北、九份、淡水、平溪、基隆、宜蘭、桃園、新竹、台中、日月潭、嘉義、阿里山、台南、高雄、墾丁、花蓮、太魯閣、台東、澎湖、桃園機場。

## 開始使用
需要 Node.js 18 以上,不用安裝任何套件:
```bash
npm start      # 開啟 http://localhost:8080
npm test       # 執行測試
```

## 專案結構
```
index.html            頁面框架
css/style.css         樣式(支援深色模式、手機版)
js/data.js            景點/美食/交通路網資料
js/planner.js         路線搜尋(Dijkstra)
js/itinerary.js       景點推薦與行程產生
js/guide.js           問導遊(關鍵字問答)
js/geo.js             距離計算、地圖連結
js/app.js             介面
sw.js                 離線快取
docs/DESIGN.md        產品設計文件與路線圖
```

> 票價與交通時間為參考值,出發前請以台灣高鐵、台鐵、客運業者公告為準。
