# 🧭 Taiwan Buddy 台灣小導遊

給**來台灣玩的外國旅客**的 App 原型:像一個會說中文的在地朋友。推薦去哪玩、規劃交通、告訴你哪裡有好吃好玩的,還能幫你跟店家、司機溝通。

英文優先,可切換中文。

## 功能
- 🆘 **救急**:給店家看的中文句卡(全螢幕大字)、自製句卡(Claude 翻譯)、珍奶點餐卡、拍照翻譯菜單/招牌(Claude 看圖)、在地人才知道的注意事項、緊急電話
- 🀄 **給司機看**:每個景點、店家都能一鍵全螢幕顯示中文名稱
- 💬 **問導遊**:「台北去台南要多久?」「花蓮三天怎麼玩?」(在 claude.ai 上由 Claude 回答,其他情況使用離線版)
- ✨ **依興趣推薦景點**(自然、老街、夜市、溫泉、親子、雨天室內…)
- 🗓️ **自動排行程**:選天數、步調、偏好,產生每日行程(含交通與美食)
- 🚆 **交通規劃**:高鐵/台鐵/捷運/客運/飛機,提供最快、最省錢、最少轉乘方案
- 🍜 **吃喝玩樂**:各城市小吃、夜市、伴手禮
- ⭐ **收藏與串聯路線**、📍 **附近景點**、📱 **可安裝、離線可用(PWA)**

涵蓋 20 個地點:台北、九份、淡水、平溪、基隆、宜蘭、桃園、新竹、台中、日月潭、嘉義、阿里山、台南、高雄、墾丁、花蓮、太魯閣、台東、澎湖、桃園機場。

## 開始使用
**最簡單:** 下載 `dist/taiwan-tour-guide.html`,直接用瀏覽器開啟(電腦、手機都可以)。

**開發模式:** 需要 Node.js 18 以上,不用安裝任何套件:
```bash
npm start      # 開啟 http://localhost:8080
npm test       # 執行測試
npm run build  # 重新產生單一檔案版 dist/taiwan-tour-guide.html
```

> 注意:`localhost` 只在執行 `npm start` 的那台電腦上打得開。

## 專案結構
```
index.html            頁面框架
css/style.css         樣式(支援深色模式、手機版)
js/data.js            景點/美食/交通路網資料(中文)
js/data-en.js         英文翻譯
js/i18n.js            語言切換與介面文字
js/phrases.js         句卡、珍奶點餐、注意事項、緊急電話
js/planner.js         路線搜尋(Dijkstra)
js/itinerary.js       景點推薦與行程產生
js/guide.js           問導遊離線版(關鍵字問答)
js/ai-guide.js        問導遊 AI 版(Claude + 查詢工具)
js/geo.js             距離計算、地圖連結
js/app.js             介面
sw.js                 離線快取
docs/DESIGN.md        產品設計文件與路線圖
```

> 票價與交通時間為參考值,出發前請以台灣高鐵、台鐵、客運業者公告為準。
